📂基本コマンド① 今どこ・何がある・移動する
コマンド名 ／ 由来(フルスペル) ／ 用途　書き方は コマンド -オプション 対象。
pwdprint working directory 今いる場所(カレントディレクトリ)のパスを表示
lslist その場所のファイル・フォルダ一覧を表示
ls -llong 1行1件で詳細表示(種類・権限・サイズ・更新日時)
ls -aall . で始まる隠しファイルも表示
ls -lhhuman readable サイズを 4.0K 12M のように読みやすく
ls -lt / -ltrtime 更新日時順 / reverse を足して古い順
ls -Ffile type 種類の記号を付ける(/ フォルダ * 実行可能)
ls -laオプションはまとめて書ける(= -l -a)
cd フォルダ名change directory そのフォルダへ移動
cd ..一つ上(親フォルダ)へ。.. = 親、. = 現在地
cd ~ / cd~ = ホーム(自分のフォルダ)。引数なしでも同じ
cd -直前にいたディレクトリへ戻る
名前の途中で Tab を押すと補完される。打ち間違い防止に必ず使うこと。
🗂️基本コマンド② 作る・コピー・移動・消す
mkdir 名前make directory フォルダを作る
mkdir -p a/b/cparents 途中の階層もまとめて作る
touch 名前空のファイルを作る(既存なら更新日時だけ変える)
cp 元 先copy ファイルをコピー
cp -r 元 先recursive フォルダを中身ごとコピー
mv 元 先move 移動。mv a.c b.c で名前の変更にもなる
rm ファイルremove 削除。ゴミ箱に入らずその場で消える
rm -r フォルダrecursive フォルダを中身ごと削除
rm -iinteractive 1件ずつ確認してから削除(安全)
rmdir 名前remove directory 空のフォルダだけ削除
cat ファイルconcatenate 中身を画面に流して表示
less ファイル長いファイルを1画面ずつ読む(q で終了)
⚠ rm に取り消しは無い。消す前に ls で確認し、* を使う指定は特に慎重に。

Gターミナル（続き）
🔌基本コマンド③ プロセスとポートを調べる・止める
PID = 実行中のプログラム(プロセス)ごとの番号。止めるときはこの番号で指定する。
psprocess status 自分が端末で動かすプロセスと PID
ps aux | grep 名前全プロセスから探す。2列目が PID
kill PID終了を頼む。まずこれ
kill -9 PIDSIGKILL 後片付けさせず強制終了。kill で止まらないときだけ
# address already in use と出たら lsof -nP -iTCP:3000 -sTCP:LISTEN COMMAND PID ... NAME node 12345 ... *:3000 (LISTEN) kill 12345 # 再びlsofで空なら解放
lsof = list open files。-n-P は IP・ポートを番号で表示(無いと 3000 が hbci と出る)。-sTCP:LISTEN でサーバ側に絞る。
⚠ 何も出ないのに使えないときは sudo lsof …。root など他ユーザーのプロセスは sudo なしでは見えない。

Iアプリのインストール
🛍️ Mac App Store最も手軽・安全
Apple の審査済みアプリ。自動アップデート対応。
  1. App Store を開き Apple Account でサインイン
  2. アプリを検索 →「入手」/ 価格ボタン →「インストール」
  3. Spotlight(⌘Space)/ アプリケーションフォルダから起動
👍 長所 安全・更新が自動・購入履歴で再DL
👎 短所 サンドボックスで機能制限あり・掲載外のアプリあり
削除: Finder の「アプリケーション」フォルダからゴミ箱へ
💿 DMG(ディスクイメージ)最も一般的
公式サイトからダウンロードする .dmg。中に .app が入っている。
  1. .dmg をダブルクリックしてマウント
  2. 開いたウインドウで アプリを「Applications」へドラッグ&ドロップ
  3. Finder サイドバーでディスクイメージの ⏏ を押して取り出す
  4. .dmg ファイルはゴミ箱へ(不要なら)
👍 長所 操作が直感的・管理者権限が不要なことが多い
👎 短所 更新は手動(アプリ内更新があれば自動)
削除: Applications からゴミ箱へ。設定は ~/Library に残る場合あり
📦 pkg(インストーラ)システム変更あり
ウィザード形式の .pkg。複数ファイル・ドライバ・ヘルパー等を配置する。
  1. .pkg をダブルクリック
  2. 「続ける」で使用許諾 → インストール先を選択
  3. Touch ID / パスワードで管理者認証
  4. 完了後、インストーラはゴミ箱へ
# ターミナルから sudo installer -pkg app.pkg -target /
削除: .app 削除だけでは不完全なことが多い → 公式アンインストーラを使う / pkgutil --files <id> で確認
🍺 Homebrew開発者向け定番
コマンドでアプリ・CLIツールを一括管理。brew.sh の手順で導入。
# GUIアプリ(Cask) brew install --cask google-chrome # CLIツール(Formula) brew install git wget brew search keyword # 検索 brew list # 一覧 brew update && brew upgrade # 更新 brew uninstall wget # 削除 brew uninstall --cask --zap app # 設定も削除 brew bundle dump # Brewfile に書き出し
👍 長所 再現しやすい・一括更新・Brewfileで環境複製
👎 短所 初回に導入作業が必要・CLIに慣れが必要
🗜️ ZIP / .app 直接配置シンプル
.zip を展開すると .app が出てくる形式。
  1. ZIP をダブルクリックで展開(自動で .app が出現)
  2. .app を「アプリケーション」フォルダへ移動
  3. 初回は一度起動を試み、警告を閉じる → システム設定 → プライバシーとセキュリティ →「このまま開く」(🔒 の欄を参照)
ダウンロードフォルダのまま起動すると自動更新・権限付与が失敗することがある。必ず Applications へ。
🧰 その他のメジャーな方法
  • 公式インストーラスクリプト: curl -fsSL URL | sh(例: Homebrew, rustup)⚠ 取得したスクリプトの中身を確認してから実行する
  • 言語ごとのパッケージ管理: pip / npm / cargo / gem など、その言語用のライブラリ・ツールを入れる仕組み
📊インストール方法の比較
方法 ／ おすすめの場面 ／ 更新 ／ 管理者権限 ／ 削除のしやすさ
App Storeまず探す場所。安全重視 ／ 更新: 自動 ／ 管理者権限: 不要 ／ 削除: ◎ 簡単
DMG / ZIP公式サイト配布の普通のアプリ ／ 更新: アプリ依存 ／ 管理者権限: 不要が多い ／ 削除: ○ ゴミ箱へ
pkgドライバ・業務ソフト・ヘルパー付き ／ 更新: アプリ依存 ／ 管理者権限: 必要 ／ 削除: △ 専用アンインストーラ推奨
Homebrew開発ツール・環境の再現・一括更新 ／ 更新: brew upgrade ／ 管理者権限: 初回のみ ／ 削除: ◎ コマンド一発
🔒 「開発元を検証できません」と表示されたらGatekeeper
