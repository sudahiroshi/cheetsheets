コンパイルと実行
gcc hello.c -o hello # コンパイル ./hello # 実行
-o 名前実行ファイル名を指定(省略すると a.out)
-Wall警告をすべて表示(常に付ける)
-gデバッグ情報を付ける(lldb 用)
-lmmath.h の関数を使うときに付ける
-c.o までで止める(分割コンパイル)
-std=c17規格を指定(Apple clang の既定は C17)
-std=c23最新規格(0b1010 などが警告なしで使える)
./現在のディレクトリのプログラムを指す

ls cd pwd などの基本コマンドと、記号の読み方・入力方法は macOS 版シート参照

F配列と文字列
配列
int a[5] = {10, 20, 30, 40, 50}; int b[5] = {0}; // すべて0 a[0] = 1; // 添字は0から int n = sizeof(a) / sizeof(a[0]); // 要素数 for (int i = 0; i < n; i++) printf("%d ", a[i]);
a[5] は範囲外(正しくは a[0]〜a[4])。エラーにならず危険
二次元配列
int m[2][3] = { {1,2,3}, {4,5,6} }; for (int i = 0; i < 2; i++) for (int j = 0; j < 3; j++) sum += m[i][j];
合計sum += m[i][j]
最大if (m[i][j] > max) max = m[i][j];
平均(double)sum / (行数 * 列数)
関数への配列の渡し方
void show(int a[], int n) { ... } show(a, 5);
先頭アドレスが渡る(コピーされない)
関数内で変更すると元の配列も変わる
要素数 n は別に渡す
