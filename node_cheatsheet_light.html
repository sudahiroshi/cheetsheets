E非同期処理
⏳同期と非同期(待たずに次へ進む)
console.log('1: 注文'); setTimeout(() => { console.log('3: 1秒後に届く'); }, 1000); console.log('2: 待たずに次へ');
時間 → 本体 1 ── 2 ── (本体はここで終わり) タイマー └──── 1秒 ────→ 3 出力: 1 → 2 → 3
ファイル読み込み・通信・タイマーのような時間のかかる処理は、終わるのを待たずに次の行へ進み、終わったら後で知らせ(コールバック)を受ける。C は1行ずつ終わるまで待つ
結果を使う処理は「知らせを受けた後」に書く。すぐ次の行に書くと、まだ値が無い
📞コールバック
const fs = require('fs'); fs.readFile('a.txt', 'utf8', cb); // 読み終わったら cb が呼ばれる function cb(err, data) { if (err) { // 失敗すると err に入る console.error(err.message); return; } console.log(data); } console.log('こちらが先に表示される');
cb のように「終わったら呼んでもらう関数」をコールバックと呼ぶ。普通はアロー関数で直接書く。第1引数がエラー、第2引数が結果(Node の約束)。入れ子が深くなりやすい(コールバック地獄)ので、新しく書くなら Promise / async を使う
🤝Promise
const fs = require('fs/promises'); fs.readFile('a.txt', 'utf8') .then(data => console.log(data)) .catch(err => console.error(err)) .finally(() => console.log('終了')); // 自分で作る例: ms ミリ秒だけ待つ const sleep = ms => new Promise( r => setTimeout(r, ms));
.then / .catch成功したとき / 失敗したときに呼ばれる
Promise「後で結果が届く」ことを表す値。成功(resolve)か失敗(reject)で終わる
Promise.all([p1, p2])全部終わるまで待つ(並行に実行)
✨async / await
const fs = require('fs/promises'); async function main() { try { const data = await fs.readFile( 'a.txt', 'utf8'); // ↑ 読み終わるまで待ってから次へ console.log(data); await sleep(1000); // 1秒待つ } catch (err) { // 失敗はここ console.error(err.message); } } main();
await は async 関数の中だけ。外で使うと SyntaxError: await is only valid in async functions and the top level bodies of modules(ES Modules ならトップレベルも可)
await を付け忘れると値ではなく Promise { <pending> } が返る
🔀3つの書き方の対応
書き方成功したとき失敗したとき
コールバック(err, data) => の dataif (err) { … }
Promise.then(data => …).catch(err => …)
async/awaitconst data = await …try { } catch (err) { }
fs/promises や fetch のように Promise を返す関数には await を付けて使う
forEach の中の await は待ってくれない。順に待つなら for (const x of list) { await … }
