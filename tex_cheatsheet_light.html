A土台とコンパイル
コンパイル手順
uplatex main.tex dvipdfmx main.dvi
DVI 経由の2段。-kanji=utf8 は既定なので省略可
latexmk 設定例 ~/.latexmkrc
$latex='uplatex -synctex=1 -halt-on-error %O %S'; $bibtex='upbibtex %O %B'; $dvipdf='dvipdfmx %O -o %D %S'; $makeindex='upmendex %O -o %D %S'; $pdf_mode=3;
uplatex 用。$pdf_mode=3 が「DVI→PDF を dvipdfmx で」
よく使うオプション
-halt-on-error -interaction=nonstopmode -synctex=1
最初のエラーで停止／対話せず最後まで／エディタ相互ジャンプ
コンパイル回数
latexmk main.tex
相互参照・目次は 2 回以上必要。latexmk が回数を自動判断
ソースは UTF-8 保存
（エディタの文字コード設定）
upLaTeX は UTF-8 が既定。inputenc は読み込まない
中間ファイル掃除
latexmk -c latexmk -C
-c は aux/log など中間物のみ、-C は生成 PDF も消す

F数式
インライン数式
$x^2+y^2=z^2$ \(x+y\)
本文中に埋め込む。$$…$$ は LaTeX では使わない
ディスプレイ数式
\[ E = mc^2 \]
別行立て。番号が要らないときの基本形
番号付き数式
\begin{equation}\label{eq:x} a^2+b^2=c^2 \end{equation}
equation* は番号なし（amsmath が必要）
番号の制御
\tag{A.1} \notag \nonumber
任意の式番号を付ける／その行だけ番号を消す
複数行（揃える）
\begin{align} a &= b + c \\ &= d \end{align}
& の位置で縦に揃う。align* は番号なし
複数行（その他）
gather multline split aligned
中央揃え／長い式を分割／1 つの番号で複数行／部分揃え。後の 2 つは equation の中で使う
場合分け
\begin{cases} 1 & (x>0) \\ 0 & (x\le 0) \end{cases}
左の大括弧付き。equation の中に入れる
分数・根号
\frac{a}{b} \dfrac{a}{b} \tfrac{a}{b} \sqrt{x} \sqrt[3]{x}
\dfrac は常にディスプレイ寸法、\tfrac は常に小さく
添字
x^{2} a_{ij} x_i^2 {}^{t}\!A
2 文字以上の添字は必ず { } で囲む
大型演算子
\sum_{i=1}^{n} \prod_{i=1}^{n} \int_a^b \iint \oint \lim_{x\to 0} \max_{i}
インラインでは上下に付かない。\limits で強制できる
括弧の自動伸縮
\left( … \right) \left\{ … \right. \bigl \Bigl \biggl \Biggl
\right. は閉じ括弧なし。手動サイズは \bigl 系

\langle\rangle\lvert\rvert\lVert\rVert\lfloor\rfloor\lceil\rceil
山括弧／絶対値／ノルム／床・天井
関数名（立体）
\sin\cos\tan\log\ln\exp\max\min\arg\det\dim\gcd
自前にないものは \operatorname{sgn} で作る
演算子・関係子
\cdot\times\div\pm\mp\leq\geq\neq\approx\simeq\equiv\sim\propto\ll\gg\in\notin\subset\subseteq\cup\cap\setminus\emptyset\forall\exists\neg\land\lor\infty\partial\nabla\to\mapsto\Rightarrow\Leftrightarrow\therefore
よく使う二項演算子・関係子・論理記号・矢印
ギリシャ文字（小文字）
\alpha\beta\gamma\delta\epsilon\varepsilon\zeta\eta\theta\vartheta\iota\kappa\lambda\mu\nu\xi\pi\rho\sigma\tau\upsilon\phi\varphi\chi\psi\omega
o（オミクロン）はラテン文字の o をそのまま使う
ギリシャ文字（大文字）
\Gamma\Delta\Theta\Lambda\Xi\Pi\Sigma\Upsilon\Phi\Psi\Omega
既定は立体。斜体にするなら \varGamma 系（amsmath）
アクセント
\hat{x}\bar{x}\vec{x}\dot{x}\ddot{x}\tilde{x}\overline{AB}\underline{x}\overrightarrow{AB}\widehat{ABC}\widetilde{ABC}

数式内の書体
\mathrm{d}\mathbf{A}\bm{x}\mathit{}\mathcal{F}\mathbb{R}\mathsf{}

数式内の日本語
\text{ただし }x>0
\text{} は amsmath。数式中に和文を直書きしない
行列
\begin{pmatrix} a & b \\ c & d \end{pmatrix} pmatrix( ) bmatrix[ ] vmatrix| | Vmatrix‖ ‖ matrix(括弧なし) array
array だけ列指定が要る。他は amsmath で括弧付き
行列の省略記号
\cdots\vdots\ddots\dots
横／縦／斜めの三点。文脈任せなら最後
数式内の空き
\,\quad\qquad\!
記号の詰まり具合を手で微調整する（最後は負の空き）
